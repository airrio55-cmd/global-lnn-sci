# STEP6A_NEXT_GATES_KO

STEP6A는 설계·동결·정적 감사·합성 시험 단계다. 실제 금융 HMM fit/filtering, 신경망 학습·재학습, Test 재추론, checkpoint load/forward, 금융 p값·bootstrap 재실행, RAW5/LOG2 Ensemble, LTC τactual, GPU 및2026가격 사용은 모두0이다. HMM100후보/최종10개는 계획이며 학습 완료가 아니다. hmm_fit_enabled=false/hmm_filtering_enabled=false를 유지한다.

STEP6B 제안 범위는 5Origin×A/B×10초기화의 최대100개 Train-only 금융 HMM candidate fit, 각 코호트 최종1개/총10개 선택, 순차 forward filtering 및 기존 Test500 예측의 레짐 기술집계다. 신경망 학습/재추론/HMM 예산 확대/금융 p값/RAW5·LOG2 Ensemble/GPU/τactual은 포함하지 않는다. 이번에는 승인되지 않았고 자동 시작하지 않는다.

별도 승인 reference에100개 identity·Train input/date/source/config/environment SHA와 범위·읽기/쓰기 경로·독립 출력 경로·예산·중복실행 차단·실패/전부 부적격 BLOCKED 규칙을 연결한다. 후속 금융 데이터빌더가 원단위 Vol_Regime/Train-only scaler/bridge/date·Target join을 검사해야 한다. 같은 초기화의 실패를 다른 Seed나 상태수로 대체하지 않는다.

A/B BOTH_UNVERIFIED, primary price PENDING, historical18:00 available_at UNKNOWN, production-PIT BLOCKED를 유지한다. O1~O4 Test 연도는 후속 Origin Validation과 중복된 역사 기간이다. HMM 레짐 역시 회고적 변동성의 기술적 분해일 뿐 새로운 전향적 검증이나 실제 거래 가능성 인증이 아니다. 기존 STEP5C 결과를 HMM 설정·초기화·상태명·가격 선택에 사용하지 않는다.

HMM/수동 레짐의 추가 유의성 검정 가족을 만들지 않는다. 원형 LNN Ensemble의 외국인순매수/Nasdaq/SOX historical PIT와 채널별 추가모델 승인은 독립적으로 해결해야 한다.

상세 금융 input/date/checkpoint/identity 매핑과 비공개 SHA 관계는 로컬 ignored 경로에만 보존한다. 공개본은 코드·구조적 계약·합성 결과·집계·비민감 해시만 포함한다.
